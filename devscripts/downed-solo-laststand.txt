# Downed state and death saves, solo. Run: timeout 400 ./gradlew runClient -PdevScript=devscripts/downed-solo-laststand.txt
# Expect in latest.log ([Downed], [D20] and [CHAT] lines):
#  1 Last Stand success (forced 18): "Last Stand succeeded", Health 1.0f; screenshot downed-laststand-success
#  2 Last Stand failure (forced 3): "Last Stand failed" and a death message
#  3 cooldown: "has no Last Stand" and an instant death, no roll
#  4 dndLastStand false and dndDeathSaves 0: instant deaths, no roll
#  5 totem in hand: the totem pops (Absorption), no [Downed] line
#  6 massive damage: "killed outright by massive damage"
#  7 /dndclass down: crawl pose (downed-crawl-back), speed modifier, saves every 6 s; 3 passes -> stable,
#    30 s later standing with Weakness
#  8 natural 20 -> "stood up with 1.0 HP"; natural 1 -> 2 fails
#  9 hits while Downed -> fails ("hit while Downed"), death with the original source
# 10 lava -> death about 3 s after going in; void and /kill -> instant
# 11 holding the power-up key 3 s -> "give in"; attack on a pig does nothing; jump does nothing
