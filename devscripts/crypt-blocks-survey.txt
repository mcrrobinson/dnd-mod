# Crypt building blocks survey (docs/items/crypt-blocks.md): the same shots as crypt-docs-rooms.txt (the docs'
# "before" pictures), with the Crypt's blocks in place. Places "The Crypt of the Ashen Queen" at 2448 64 -2400
# (floor y=41; /place gives the same layout there each time). Destructive: use a scratch run dir.
# Room centres (/dungeon info): antechamber 2471 -2393, mid-boss 2455 -2441, boss 2431 -2433, reliquary 2407 -2441.
# Run: timeout 600 ./gradlew runClient -PdevRunDir=run-crypt -PdevWidth=1920 -PdevHeight=1080 -PdevScript=devscripts/crypt-blocks-survey.txt
wait 40
closescreen

/time set noon
/weather clear
/difficulty normal
/gamerule doDaylightCycle false
/gamerule doMobSpawning false
/gamemode creative
/effect give @s minecraft:night_vision 99999 0 true
/tp @s 2455 200 -2393
