# Checks Cogsdeep's building blocks (docs/structures/cogsdeep-blocks.md): a showcase, the pipework joining up, the
# clockface keeping time, drops, recipes, the blueprint table's grid and the Tinker's new offers.
# Run: timeout 300 ./gradlew runClient -PdevScript=devscripts/cogsdeep-blocks.txt
# Expect in latest.log:
# - "Test passed" for each /execute if block line (pipework east/west/up joins, no join up to a solid block, the
#   clockface at hour=3 at 3:30 pm)
# - each /loot line drops its own block ("Dropped 1 [...]"); "Unlocked"/"No new recipes" for each /recipe line
# - the blueprint table: a crafting grid ("slots" after placing logs shows Oak Log in slot 1 and 4 Oak Planks in 0)
# - the Tinker: after `trade 11`, 8 Riveted Brass in the merchant result slot (2)
# Screenshots: cogsdeep-blocks-showcase, -close-gears, -close-clock, -night, -blueprint, -tinker

# The clockface: set at hour 0 at day time 9500 (3:30 pm), a random tick (sped up here) puts the hand to 3. (Its
# hourly block tick was checked on a fresh world: placed at 8990 it turned to 3 at 9001. On a rerun the tick left
# queued at that spot from the last run stands in for it, so this checks the random tick instead.)
/time set 9500
/setblock 29 152 3 dndclasses:clockface[facing=north,hour=0]
/gamerule randomTickSpeed 4096
waitserver 10
/gamerule randomTickSpeed 3
/execute if block 29 152 3 dndclasses:clockface[hour=3]
/gamerule doDaylightCycle false
/time set noon
/tp @s 25.5 151 1.5 0 12
wait 40
hud off
screenshot cogsdeep-blocks-showcase
