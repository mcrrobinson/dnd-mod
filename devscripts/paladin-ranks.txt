# Checks Divine Judgment (Paladin special) at every rank. Run: timeout 400 ./gradlew runClient -PdevScript=devscripts/paladin-ranks.txt
# Each rank: four frozen 100 HP zombies with Fire Resistance (so beam fire doesn't skew Health) and a pig. Midnight, so no sunburn.
# The Paladin looks at zombie a (4.5 150 7.5). b is 2 blocks east of a, c 3.5 blocks west, d 4.5 blocks south.
# Undead take 50% more; the shockwave deals 40% of the beam's damage; extra beams pick the nearest hostiles.
# Expect in latest.log ([CHAT] /data get lines, order a b c d pig):
#  0. no target: sky and behind glass both give "No target..." on the action bar and keep the mana,
#     so the rank I cast right after still fires
#  I   (8 dmg, r3, 1 beam):  a 88.0  b 95.2  c 100.0 d 100.0 pig 10.0
#  II  (12 dmg, r4, 1 beam): a 82.0  b 92.8  c 92.8  d 100.0 pig 10.0
#  III (16 dmg, r5, 2 beams): a 76.0 b 76.0  c 90.4  d 90.4  pig 10.0
#  IV  (20 dmg, r6, 3 beams): a 70.0 b 70.0  c 70.0  d 88.0  pig 10.0
#  zombie a: Fire > 0 after each cast
#  Divine Smite is unlocked before rank IV: it is melee only, so the rank IV numbers don't change
# Circle of Healing (7 mana): a 12-block fall hurts the Paladin (26 max health), then the cast
#  heals to 26.0 and gives Absorption I (Id 22, Amplifier 0, ~600 ticks); AbsorptionAmount 4.0
# Screenshots: paladin-no-target, paladin-wall, paladin-rank1..4, paladin-tree, paladin-heal
