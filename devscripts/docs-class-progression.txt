# Screenshots: progression-table (the Attunement Table block), progression-tree (Necromancer tree with rank pips),
# progression-bestiary (Druid bestiary tab: Wild Shape rank II, cow and wolf unlocked (green), pig ready (gold),
# horse (tier III) and owlbear (tier IV) locked (grey)), progression-budget (Thief Rogue at level 10 with every
# reachable node and Vanish IV: 0 points left, Danger Sense's tooltip says "Next rank needs 1 point").
# Expect in latest.log: the Druid's progress line (bestiary [minecraft:cow, minecraft:wolf]) and the Rogue's
# (subclass rogue.thief, 0 points).
wait 40
closescreen
/gamemode creative
/gamerule doDaylightCycle false
/gamerule doMobSpawning false
/gamerule doWeatherCycle false
/weather clear
/time set noon
/fill -4 149 -4 12 149 12 minecraft:polished_deepslate
/fill -4 150 -4 12 156 12 minecraft:air
/kill @e[type=!minecraft:player]
/dndclass set @s necromancer
wait 10
closescreen
/dndclass resetprogress @s
/dndclass xp @s set 2700
skill unlock necromancer.bone_armor
skill unlock necromancer.life_drain
skill unlock necromancer.grave_pact
/dndclass rank @s necromancer.raise_dead 4
/setblock 4 150 4 dndclasses:attunement_table
/setblock 3 150 4 minecraft:bookshelf
/setblock 5 150 4 minecraft:bookshelf
/tp @s 4.5 151.2 1.8 0 30
hud off
wait 40
screenshot progression-table
/tp @s 6.5 151.5 1.5 35 30
wait 10

wait 10
use
