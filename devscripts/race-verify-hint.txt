# The race picker's hint line: a classed player is told their class stays; a classless one that the class picker comes next.
# Expect: rv-hint-classed says "Your class stays the same."; rv-hint-new says "Your class comes next."
wait 40
racepicker on
/dndrace set @s none
wait 20
screenshot rv-hint-classed
/dndclass set @s none
wait 20
/dndrace set @s none
wait 20
screenshot rv-hint-new
racepick dwarf
wait 10
/dndclass set @s barbarian
wait 10
quit
